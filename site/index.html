Scan

Find your games

One pass over the launchers you enable. Each game's executable is read to learn its graphics API, whether it ships DLSS, and whether an anti-cheat is in the folder.

Open a game

Read one sentence

shim-dlss5 says which route it would take and why, and lists every file it would add or replace. Nothing runs from that view.

Install

Then play. Or Remove.

Every overwritten file is backed up first, every write is recorded before it happens. Remove walks the record backwards and restores the folder byte for byte.

What a DLSS 5 install consists of

Only components fetched from their publishers' own release pages, pinned by version and SHA-256, verified before unpacking, never executed by shim.

You supply the model. The DLSS 5 model, nvngx_dlssnr.dll, is an NVIDIA file. shim-dlss5 never downloads, hosts or mirrors it. You point shim-dlss5 at your copy; it shows the file's SHA-256 and whether its NVIDIA signature is intact.

The same goes for the RenoDX DLSS 5 add-on, which its authors publish on their Discord, not on a release page.

shim-dlss5 bundles nothing and sends nothing. There is no telemetry, no account, no background service.

It tells you what happened

After a run, the Game page pulls the decisive lines out of the component's log beside the executable, so a failure is readable without opening a file.

That is the block to paste into a bug report for the add-on's authors. A crash in a game is almost never a mystery once those lines are in front of you.

Questions

The ones that come up.

Will this get me banned in an online game?

It can. Injecting a proxy DLL into a game with kernel anti-cheat (Easy Anti-Cheat, BattlEye, Vanguard, Ricochet and others) is exactly what those systems look for. shim-dlss5 detects the markers, blocks the game, and only proceeds after you type a confirmation. Use it in single-player games and benchmarks.

Windows says the installer is unrecognised.

The binaries are not code-signed yet; a certificate is one of the things sponsorship goes towards. Every release publishes SHA256SUMS.txt. Verify the hash, then choose "Run anyway". The portable exe works the same way without installing.

Which GPU do I need?

An NVIDIA RTX card. Which generations run the neural pass depends on the model build you have. The log readout in shim-dlss5 tells you if the model refused your card. Memory matters more than you'd think: a 12 GB card at 4K with frame generation on is already full before the pass starts.

Where do I get the model and the add-on?

Not from shim-dlss5, and not from this site. The model is an NVIDIA file; the RenoDX DLSS 5 add-on is published on the RenoDX Discord. shim-dlss5 records the hash and signature of whatever you point it at, so you know what you have.

Does Remove really put everything back?

Yes. Every file shim-dlss5 overwrote was copied to a backup first and is copied back; every file it added is deleted; the logs and captures the components wrote while running are removed too, unless they already existed before the install. A journal written before each step means even a crash mid-install is undone at the next start. shim-dlss5 never deletes by file name and never touches a ReShade or OptiScaler install it did not make.

Is it open source?

MIT, on GitHub. Rust core with 170 tests that run on Windows, macOS and Linux; a Tauri shell; nothing bundled. The components it fetches keep their own licences.
